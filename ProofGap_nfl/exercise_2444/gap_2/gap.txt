ASSUM:
1. a ∈ RealSet ∧ a > 0
2. x : RealSet → RealSet
3. y : RealSet → RealSet
4. s ∈ RealSet
5. forall (t), t ∈ RealSet ∧ 0 ≤ t ∧ t ≤ 2 * π ⇒ x(t) = a * (cos(t) + t * sin(t))
6. forall (t), t ∈ RealSet ∧ 0 ≤ t ∧ t ≤ 2 * π ⇒ y(t) = a * (sin(t) - t * cos(t))
7. s = DefInt(0, 2 * π, (fun t [t ∈ RealSet ∧ 0 < t ∧ t < 2 * π] . sqrtn(2, FunDeri(x, 1, 1)(t)^{2} + FunDeri(y, 1, 1)(t)^{2})) * diff(fun t [t ∈ RealSet ∧ 0 < t ∧ t < 2 * π] . t))
8. forall (t), t ∈ RealSet ∧ 0 < t ∧ t < 2 * π ⇒ FunDeri(x, 1, 1)(t) = a * t * cos(t)

GOAL:
forall (t), t ∈ RealSet ∧ 0 < t ∧ t < 2 * π ⇒ FunDeri(y, 1, 1)(t) = a * t * sin(t)
