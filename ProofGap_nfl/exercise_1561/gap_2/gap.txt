PROOF GAP @2
ASSUM:
1. S ∈ RealSet ∧ S > 0
2. f : RealSet → RealSet
3. forall (x), x ∈ RealSet ∧ x > 0 ⇒ f(x) = 2 * (x + frac(S, x))
4. forall (x), x ∈ RealSet ∧ x > 0 ⇒ FunDeri(f, 1, 1)(x) = 2 * (1 - frac(S, x^{2}))

GOAL:
forall (x), x ∈ RealSet ∧ FunDeri(f, 1, 1)(x) = 0 ⇒ x = sqrtn(2, S)
