PROOF GAP @2
ASSUM:
1. z : CartesianProd(RealSet, RealSet) → RealSet
2. F : CartesianProd(RealSet, CartesianProd(RealSet, RealSet)) → RealSet
3. a ∈ RealSet ∧ a ≠ 0
4. b ∈ RealSet ∧ b ≠ 0
5. a * b ≠ 0
6. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ⇒ z(x, y) = frac(x, a) + frac(y, b)
7. F = (fun x, y, λ [x ∈ RealSet ∧ y ∈ RealSet ∧ λ ∈ RealSet] . frac(x, a) + frac(y, b) + λ * (x^{2} + y^{2} - 1))
8. forall (x) (y) (λ), x ∈ RealSet ∧ y ∈ RealSet ∧ λ ∈ RealSet ⇒ FunDeri(F, 1, 1)(x, y, λ) = frac(1, a) + 2 * λ * x

GOAL:
forall (x) (y) (λ), x ∈ RealSet ∧ y ∈ RealSet ∧ λ ∈ RealSet ⇒ FunDeri(F, 2, 1)(x, y, λ) = frac(1, b) + 2 * λ * y
