PROOF GAP @5
ASSUM:
1. x ∈ RealSet
2. y ∈ RealSet
3. |x| < 1
4. |y| < 1
5. cos(y) ≠ 0 ⇒ frac(cos(x), cos(y)) = cos(x) * (1 - sin(y)^{2})^{-frac(1, 2)}
6. cos(x) ≈_{ x^{4} } 1 - frac(x^{2}, 2)
7. (1 - sin(y)^{2})^{-frac(1, 2)} ≈_{ y^{4} } 1 + frac(1, 2) * y^{2}
8. frac(cos(x), cos(y)) ≈_{ (x^{2} + y^{2})^{2} } (1 - frac(x^{2}, 2)) * (1 + frac(y^{2}, 2))

GOAL:
frac(cos(x), cos(y)) ≈_{ (x^{2} + y^{2})^{2} } 1 - frac(1, 2) * (x^{2} - y^{2})

METHOD:
