PROOF GAP @2
ASSUM:
1. x_{0} ∈ RealSet
2. f : RealSet → RealSet
3. F : RealSet → RealSet
4. a ∈ RealSet
5. b ∈ RealSet
6. Defined(f, (-∞, x_{0}])
7. LeftDiffableFuncAt(f, x_{0})
8. forall (x), x ∈ RealSet ⇒ F(x) = cases{ f(x) if x ≤ x_{0}; a * x + b if x > x_{0} }
9. F(x_{0}) = f(x_{0})

GOAL:
f(x_{0}) = lim_{ x → x_{0}^- } (F(x))
