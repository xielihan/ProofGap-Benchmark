PROOF GAP @2
ASSUM:
1. z : CartesianProd(RealSet, RealSet) → RealSet
2. n ∈ NonNegIntegerSet ∧ n ∈ PosIntegerSet
3. FuncOfClassKOn(z, CartesianProd(RealSet, RealSet), n)
4. (forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ⇒ FunDeri(z, 2, n)(x, y) = 0) ⇒ (exists (φ), φ : CartesianProd(NonNegIntegerSet, RealSet) → RealSet ∧ (forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ⇒ FunDeri(z, 2, n - 1)(x, y) = (n - 1)! * φ(n - 1, x)))

GOAL:
(forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ⇒ FunDeri(z, 2, n)(x, y) = 0) ⇒ (exists (φ), φ : CartesianProd(NonNegIntegerSet, RealSet) → RealSet ∧ (forall (j) (x) (y), j ∈ NonNegIntegerSet ∧ j ≤ n - 1 ∧ x ∈ RealSet ∧ y ∈ RealSet ⇒ FunDeri(z, 2, j)(x, y) = sum_{ i = j }^{ n - 1 } (frac(i!, (i - j)!) * y^{i - j} * φ(i, x))))
