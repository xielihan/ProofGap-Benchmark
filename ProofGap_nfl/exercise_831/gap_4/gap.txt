PROOF GAP @4
ASSUM:
1. f : RealSet → RealSet
2. forall (x), x ∈ RealSet ∧ x ∈ NonNegRealSet ⇒ f(x) = x + (x - 1) * arcsin(sqrtn(2, frac(x, x + 1)))
3. forall (x), x ∈ RealSet ∧ x > 0 ⇒ FunDeri(f, 1, 1)(x) = 1 + arcsin(sqrtn(2, frac(x, x + 1))) + frac(x - 1, 2 * (x + 1) * sqrtn(2, x))
4. FunDeri(f, 1, 1)(1) = 1 + arcsin(frac(1, sqrtn(2, 2)))
5. arcsin(frac(1, sqrtn(2, 2))) = frac(π, 4)

GOAL:
FunDeri(f, 1, 1)(1) = 1 + frac(π, 4)
