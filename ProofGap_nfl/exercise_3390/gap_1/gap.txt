1. z : CartesianProd(RealSet, RealSet) → RealSet
2. a ∈ RealSet
3. b ∈ RealSet
4. c ∈ RealSet
5. a ∈ RealSet \ { 0 }
6. b ∈ RealSet \ { 0 }
7. c ∈ RealSet \ { 0 }
8. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ⇒ z(x, y) ≠ 0 ∧ frac(x^{2}, a^{2}) + frac(y^{2}, b^{2}) + frac(z(x, y)^{2}, c^{2}) = 1
