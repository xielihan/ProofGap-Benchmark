PROOF GAP @10
ASSUM:
1. f : RealSet → RealSet
2. c ∈ RealSet
3. forall (x), x ∈ RealSet ∧ x ≥ 0 ⇒ f(x) = cases{ frac(3 - x^{2}, 2) if 0 ≤ x ∧ x ≤ 1; frac(1, x) if 1 < x ∧ x < +∞ }
4. f(0) = frac(3, 2)
5. f(2) = frac(1, 2)
6. forall (x), x ∈ RealSet ∧ x > 0 ⇒ FunDeri(f, 1, 1)(x) = cases{ -x if 0 < x ∧ x ≤ 1; -frac(1, x^{2}) if 1 < x ∧ x < +∞ }
7. f(2) - f(0) = FunDeri(f, 1, 1)(c) * (2 - 0)
8. 0 < c
9. c < 2
10. frac(1, 2) - frac(3, 2) = -c * (2 - 0) ∨ frac(1, 2) - frac(3, 2) = -frac(1, c^{2}) * (2 - 0)
11. c = frac(1, 2) ∨ c = sqrtn(2, 2) ∨ c = -sqrtn(2, 2)
12. ¬(-sqrtn(2, 2) > 0 ∧ -sqrtn(2, 2) < 2)

GOAL:
c ∈ { frac(1, 2), sqrtn(2, 2) } ⇔ 0 < c ∧ c < 2 ∧ f(2) - f(0) = FunDeri(f, 1, 1)(c) * (2 - 0)
