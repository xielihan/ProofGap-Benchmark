ASSUM:
1. y : RealSet → RealSet
2. forall (x), x ∈ RealSet ∧ x ∈ PosRealSet ⇒ y(x) ∈ PosRealSet ∧ x ≠ y(x) ∧ x^{y(x)} = y(x)^{x}
3. forall (x), x ∈ RealSet ∧ x ∈ PosRealSet ⇒ y(x) * ln(x) = x * ln(y(x))
4. forall (x), x ∈ RealSet ∧ x ∈ PosRealSet ⇒ frac(ln(x), x) = frac(ln(y(x)), y(x))

forall (x), x ∈ RealSet ∧ x ∈ PosRealSet ⇒ frac(1 - ln(x), x^{2}) = frac(FunDeri(y, 1, 1)(x) * (1 - ln(y(x))), y(x)^{2})
