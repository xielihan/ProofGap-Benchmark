ASSUM:
1. y : RealSet → RealSet

4. forall (x), x ∈ RealSet ∧ x > 0 ⇒ FunDeri(y, 1, 1)(x) = x^{frac(1, x) - 2} * (1 - ln(x))
5. forall (x), x ∈ RealSet ∧ x > 0 ∧ FunDeri(y, 1, 1)(x) = 0 ⇒ 1 - ln(x) = 0

forall (x), x ∈ RealSet ∧ x > 0 ∧ FunDeri(y, 1, 1)(x) = 0 ⇒ x = e
