PROOF GAP @3
ASSUM:
1. z : CartesianProd(RealSet, RealSet) → RealSet
2. D ⊆ CartesianProd(RealSet, RealSet)
3. x ∈ RealSet
4. y ∈ RealSet
5. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ⇒ z(x, y) = x - 2 * y - 3
6. D = { (x, y) | x ∈ RealSet, y ∈ RealSet, 0 ≤ x ∧ x ≤ 1, 0 ≤ y ∧ y ≤ 1, 0 ≤ x + y ∧ x + y ≤ 1 }
7. ContinuousFuncOn(z, D)
8. D = { (x, y) | x ∈ RealSet, y ∈ RealSet, 0 ≤ x ∧ x ≤ 1, y = 0 } ∪ { (x, y) | x ∈ RealSet, y ∈ RealSet, x = 0, 0 ≤ y ∧ y ≤ 1 } ∪ { (x, y) | x ∈ RealSet, y ∈ RealSet, x + y = 1, 0 ≤ x ∧ x ≤ 1 }

GOAL:
forall (x), x ∈ RealSet ∧ 0 ≤ x ∧ x ≤ 1 ⇒ z(x, 0) = x - 3

METHOD:
