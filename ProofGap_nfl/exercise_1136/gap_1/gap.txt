PROOF GAP @1
ASSUM:
1. y : CartesianProd(RealSet, RealSet) → RealSet
2. u : RealSet → RealSet
3. v : RealSet → RealSet
4. m ∈ RealSet
5. n ∈ RealSet
6. forall (x), x ∈ RealSet ⇒ u(x) > 0
7. forall (x), x ∈ RealSet ⇒ v(x) > 0
8. DiffableFunc(u)
9. DiffableFunc(v)
10. DiffableFunc(FunDeri(u, 1, 1))
11. DiffableFunc(FunDeri(v, 1, 1))
12. forall (x), x ∈ RealSet ∧ u(x) > 0 ∧ v(x) > 0 ⇒ y(u(x), v(x)) = u(x)^{m} * v(x)^{n}

GOAL:
forall (x), x ∈ RealSet ∧ u(x) > 0 ∧ v(x) > 0 ⇒ FunDeri(fun t . y(u(t), v(t)), 1, 1)(x) = m * u(x)^{m - 1} * v(x)^{n} * FunDeri(u, 1, 1)(x) + n * u(x)^{m} * v(x)^{n - 1} * FunDeri(v, 1, 1)(x)
