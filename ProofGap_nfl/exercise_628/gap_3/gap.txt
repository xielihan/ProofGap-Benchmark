1. x ∈ RealSet
2. |sum_{ k = n + 1 }^{ 2 * n } (frac(x^{k}, k!))| ≤ sum_{ k = n + 1 }^{ 2 * n } (frac(|x|^{k}, k!))

GOAL:
forall (n), n ∈ NonNegIntegerSet ∧ n > 0 ∧ |x| = 1 ⇒ frac(|x|^{n + 1}, (n + 1)!) * n = frac(n, (n + 1)!)
