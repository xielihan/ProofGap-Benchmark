PROOF GAP @3
ASSUM:
1. y : RealSet → RealSet
2. FuncOfClassK(y, 3)
3. exists (`ϵ`), `ϵ` ∈ RealSet ∧ `ϵ` > 0 ∧ Defined(y, (-`ϵ`, `ϵ`))
4. forall (x), x ∈ RealSet ⇒ x^{2} - x * y(x) + 2 * y(x)^{2} + x - y(x) - 1 = 0
5. forall (x), x ∈ RealSet ⇒ 2 * x - y(x) - x * FunDeri(y, 1, 1)(x) + 4 * y(x) * FunDeri(y, 1, 1)(x) + 1 - FunDeri(y, 1, 1)(x) = 0
6. FunDeri(y, 1, 1)(0) = 0

GOAL:
forall (x), x ∈ RealSet ⇒ 2 - FunDeri(y, 1, 1)(x) - FunDeri(y, 1, 1)(x) - x * FunDeri(y, 1, 2)(x) + 4 * FunDeri(y, 1, 1)(x)^{2} + 4 * y(x) * FunDeri(y, 1, 2)(x) - FunDeri(y, 1, 2)(x) = 0
