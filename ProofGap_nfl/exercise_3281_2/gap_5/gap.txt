PROOF GAP @5
ASSUM:
1. u : CartesianProd(RealSet, RealSet) \ { (0, 0) } → RealSet
2. Δu : CartesianProd(RealSet, RealSet) \ { (0, 0) } → RealSet
3. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ (x, y) ∈ CartesianProd(RealSet, RealSet) \ { (0, 0) } ⇒ u(x, y) = ln(sqrtn(2, x^{2} + y^{2}))
4. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ (x, y) ∈ CartesianProd(RealSet, RealSet) \ { (0, 0) } ⇒ Δu(x, y) = FunDeri(u, 1, 2)(x, y) + FunDeri(u, 2, 2)(x, y)
5. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ (x, y) ∈ CartesianProd(RealSet, RealSet) \ { (0, 0) } ⇒ FunDeri(u, 1, 1)(x, y) = frac(x, x^{2} + y^{2})
6. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ (x, y) ∈ CartesianProd(RealSet, RealSet) \ { (0, 0) } ⇒ FunDeri(u, 1, 2)(x, y) = frac(y^{2} - x^{2}, (x^{2} + y^{2})^{2})
7. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ (x, y) ∈ CartesianProd(RealSet, RealSet) \ { (0, 0) } ⇒ FunDeri(u, 2, 2)(x, y) = frac(x^{2} - y^{2}, (x^{2} + y^{2})^{2})
8. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ (x, y) ∈ CartesianProd(RealSet, RealSet) \ { (0, 0) } ⇒ Δu(x, y) = frac(y^{2} - x^{2}, (x^{2} + y^{2})^{2}) + frac(x^{2} - y^{2}, (x^{2} + y^{2})^{2})

GOAL:
forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ (x, y) ∈ CartesianProd(RealSet, RealSet) \ { (0, 0) } ⇒ frac(y^{2} - x^{2}, (x^{2} + y^{2})^{2}) + frac(x^{2} - y^{2}, (x^{2} + y^{2})^{2}) = 0
