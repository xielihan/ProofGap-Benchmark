PROOF GAP @3
ASSUM:
1. forall (x), x ∈ RealSet ∧ -1 < x ∧ x < 1 ∧ x ≠ 0 ⇒ sqrtn(2, 1 + x) + sqrtn(2, 1 - x) ≠ 0
2. forall (x), x ∈ RealSet ∧ -1 < x ∧ x < 1 ∧ x ≠ 0 ⇒ sqrtn(3, (1 + x)^{2}) + sqrtn(3, 1 - x^{2}) + sqrtn(3, (1 - x)^{2}) ≠ 0

GOAL:
lim_{ x → 0 } (frac(sqrtn(2, 1 + x) - sqrtn(2, 1 - x), sqrtn(3, 1 + x) - sqrtn(3, 1 - x))) = lim_{ x → 0 } (frac((sqrtn(2, 1 + x) - sqrtn(2, 1 - x)) * (sqrtn(2, 1 + x) + sqrtn(2, 1 - x)), (sqrtn(3, 1 + x) - sqrtn(3, 1 - x)) * (sqrtn(2, 1 + x) + sqrtn(2, 1 - x))) * frac(sqrtn(3, (1 + x)^{2}) + sqrtn(3, 1 - x^{2}) + sqrtn(3, (1 - x)^{2}), sqrtn(3, (1 + x)^{2}) + sqrtn(3, 1 - x^{2}) + sqrtn(3, (1 - x)^{2})))
