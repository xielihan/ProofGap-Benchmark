ASSUM:
1. a : NonNegIntegerSet → RealSet
2. x ∈ RealSet
3. x ≠ -1

7. x > 0 ⇒ AbsoluteConvergentSeries(sum_{ n = 0 }^{ +∞ } (frac(1, 2 * n + 1) * frac(1 - x, 1 + x)^{n}))

x = 0 ⇒ sum_{ n = 0 }^{ +∞ } (frac(1, 2 * n + 1) * frac(1 - x, 1 + x)^{n}) = sum_{ n = 0 }^{ +∞ } (frac(1, 2 * n + 1))
