ASSUM:
1. a : NonNegIntegerSet → RealSet
2. x ∈ RealSet
3. x ≠ 0
4. forall (n), n ∈ NonNegIntegerSet ∧ n ∈ PosIntegerSet ⇒ a(n) = sin(frac(π, 2^{n}))
5. lim_{ n → +∞ } (|frac(a(n), a(n + 1))|) = lim_{ n → +∞ } (frac(sin(frac(π, 2^{n})), sin(frac(π, 2^{n + 1}))))
6. lim_{ n → +∞ } (frac(sin(frac(π, 2^{n})), sin(frac(π, 2^{n + 1})))) = lim_{ n → +∞ } (frac(frac(π, 2^{n}), frac(π, 2^{n + 1})))
7. lim_{ n → +∞ } (frac(frac(π, 2^{n}), frac(π, 2^{n + 1}))) = 2
8. lim_{ n → +∞ } (|frac(a(n), a(n + 1))|) = 2
9. |frac(1, x)| < 2 ⇒ |x| > frac(1, 2)

|frac(1, x)| < 2 ⇒ AbsoluteConvergentSeries(sum_{ n = 1 }^{ +∞ } (frac(1, x^{n}) * sin(frac(π, 2^{n}))))
