1. a ∈ RealSet
2. b ∈ RealSet
3. n ∈ NonNegIntegerSet ∧ n > 0
4. i ∈ IntegerSet
5. 0 < a
6. a < b

8. n ∈ PosIntegerSet ⇒ q^{n} = frac(b, a)

GOAL:
exists (x), x : NonNegIntegerSet → RealSet ∧ (forall (i), i ∈ IntegerSet ∧ 0 ≤ i ∧ i ≤ n ⇒ x(i) = a * q^{i})
