PROOF GAP @2
ASSUM:
1. a ∈ RealSet
2. f : RealSet → RealSet
3. φ : RealSet → RealSet
4. exists (δ), δ ∈ RealSet ∧ δ > 0 ∧ (forall (Δx), Δx ∈ RealSet ∧ (Δx > -δ ∧ Δx < δ) ⇒ f(a + Δx) = Δx * φ(a + Δx))
5. exists (δ), δ ∈ RealSet ∧ δ > 0 ∧ Defined(φ, (a - δ, a + δ)) ∧ ContinuousFuncAt(φ, a)
6. f(a) = 0

GOAL:
lim_{ Δx → 0 } (frac(f(a + Δx) - f(a), Δx)) = lim_{ Δx → 0 } (frac(Δx * φ(a + Δx) - 0, Δx))

METHOD:
