forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ FunDeri(z, 1, 1)(x, y) = 0 ∧ FunDeri(z, 2, 1)(x, y) = 0 ⇒ (x, y) ∈ { (0, 0), (-frac(1, 4), -frac(1, 2)) }
