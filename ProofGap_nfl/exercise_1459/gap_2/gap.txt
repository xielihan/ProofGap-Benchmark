PROOF GAP @2
ASSUM:
1. f : RealSet → RealSet
2. g : RealSet → RealSet
3. Δ ∈ RealSet
4. forall (x), x ∈ RealSet ∧ x ∈ [0, 1] ⇒ f(x) = x^{2}
5. forall (x), x ∈ RealSet ∧ x ∈ [0, 1] ⇒ g(x) = x^{3}
6. forall (x), x ∈ RealSet ∧ x ∈ [0, 1] ⇒ Δ = sup({ |f(x) - g(x)| | x ∈ [0, 1] })
7. forall (x), x ∈ RealSet ∧ x ∈ [0, 1] ⇒ f(x) - g(x) = x^{2} - x^{3}

GOAL:
forall (x), x ∈ RealSet ∧ x ∈ [0, 1] ⇒ FunDeri(f, 1, 1)(x) - FunDeri(g, 1, 1)(x) = 2 * x - 3 * x^{2}
