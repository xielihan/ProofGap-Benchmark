3. forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ 0 < x ∧ x < y ⇒ u(x, y) = arccos(frac(sqrtn(2, x), sqrtn(2, y)))

forall (x) (y), x ∈ RealSet ∧ y ∈ RealSet ∧ 0 < x ∧ x < y ⇒ FunDeri(u, 1, 1)(x, y) = -frac(1, 2 * sqrtn(2, x * (y - x)))
