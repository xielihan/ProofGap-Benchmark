PROOF GAP @2
ASSUM:
1. x ∈ RealSet
2. s : NonNegIntegerSet → RealSet
3. |x| > 1
4. forall (n), n ∈ NonNegIntegerSet ∧ n ∈ PosIntegerSet ⇒ s(n) = frac(x^{n + 1}, (1 - x^{n}) * (1 - x^{n + 1}))
5. forall (n), n ∈ NonNegIntegerSet ∧ n ∈ PosIntegerSet ⇒ frac(1, 1 - x^{n}) - frac(1, 1 - x^{n + 1}) = frac(1 - x, x) * s(n)

GOAL:
forall (N), N ∈ NonNegIntegerSet ∧ N ∈ PosIntegerSet ⇒ sum_{ k = 1 }^{ N } (frac(1 - x, x) * s(k)) = frac(1, 1 - x) - frac(1, 1 - x^{N + 1})
