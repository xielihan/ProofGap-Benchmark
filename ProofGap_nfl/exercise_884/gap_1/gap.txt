ASSUM:
1. y : RealSet → RealSet

3. b ∈ RealSet ∧ b > 0
4. forall (x), x ∈ RealSet ∧ x > 0 ⇒ y(x) = frac(a, b)^{x} * frac(b, x)^{a} * frac(x, a)^{b}

forall (x), x ∈ RealSet ∧ x > 0 ⇒ ln(y(x)) = x * ln(frac(a, b)) + a * (ln(b) - ln(x)) + b * (ln(x) - ln(a))
