PROOF GAP @3
ASSUM:
1. x ∈ RealSet
2. cos(x) ≠ 0
3. cos(3 * x) ≠ 0
4. tan(x) ≠ 0
5. lim_{ x → frac(π, 2) } (frac(tan(3 * x), tan(x))) = lim_{ x → frac(π, 2) } (frac(3 * sec(3 * x)^{2}, sec(x)^{2}))
6. lim_{ x → frac(π, 2) } (frac(3 * sec(3 * x)^{2}, sec(x)^{2})) = 3 * (lim_{ x → frac(π, 2) } (frac(cos(x), cos(3 * x))))^{2}

GOAL:
lim_{ x → frac(π, 2) } (frac(cos(x), cos(3 * x))) = lim_{ x → frac(π, 2) } (frac(sin(x), 3 * sin(3 * x)))

METHOD:
[@method 根据 "洛必达法则" @]
