PROOF GAP @1
ASSUM:
1. f : RealSet → RealSet
2. φ : RealSet → RealSet
3. ContinuousFuncOn(f, [0, +∞))
4. forall (x), x ∈ RealSet ∧ x ∈ [0, +∞) ⇒ f(x) > 0
5. forall (x), x ∈ RealSet ∧ x > 0 ⇒ φ(x) = frac(DefInt(0, x, (fun t [t ∈ RealSet] . t * f(t)) * diff(fun t [t ∈ RealSet] . t)), DefInt(0, x, (fun t [t ∈ RealSet] . f(t)) * diff(fun t [t ∈ RealSet] . t)))

GOAL:
lim_{ x → 0^+ } (φ(x)) = lim_{ x → 0^+ } (frac(x * f(x), f(x)))

METHOD:
[@method 使用洛必达法则和变上限积分求导法则 @]
