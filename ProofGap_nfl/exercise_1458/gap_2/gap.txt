6. forall (x), x ∈ RealSet ∧ x ∈ IntervalLoRo(-1, 1) ⇒ FunDeri(P, 1, 1)(x) = 2 * x

forall (x), x ∈ RealSet ∧ x ∈ IntervalLoRo(-1, 1) ⇒ (FunDeri(P, 1, 1)(x) = 0 ⇔ x = 0)
