PROOF GAP @3
ASSUM:
1. f : RealSet → RealSet
2. a ∈ RealSet
3. b ∈ RealSet
4. a < b
5. forall (x), x ∈ RealSet ⇒ f(x) = cases{ sin(frac(1, x - a)) if x ≠ a; 0 if x = a }
6. f(a) = 0
7. |f(b)| ≤ 1

GOAL:
forall (y), y ∈ RealSet ∧ y ∈ [-1, 1] ⇒ (exists (x), x ∈ RealSet ∧ x ∈ (a, b] ∧ f(x) = y)
