PROOF GAP @2
ASSUM:
1. a ∈ RealSet
2. b ∈ RealSet
3. forall (x), x ∈ RealSet ∧ x > max(-a, -b, 0) ⇒ sqrtn(2, (x + a) * (x + b)) - x = frac((x + a) * (x + b) - x^{2}, sqrtn(2, (x + a) * (x + b)) + x)

GOAL:
forall (x), x ∈ RealSet ∧ x > -a ∧ x > -b ∧ x > 0 ⇒ frac((x + a) * (x + b) - x^{2}, sqrtn(2, (x + a) * (x + b)) + x) = frac(a + b + frac(a * b, x), 1 + sqrtn(2, (1 + frac(a, x)) * (1 + frac(b, x))))
