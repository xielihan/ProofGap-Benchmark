1. α ∈ RealSet
2. I : RealSet → RealSet
3. forall (β), β ∈ RealSet ⇒ I(β) = DefInt(0, +∞, frac(sin(β * x), x)^{2} * diff(x))
4. α ≥ 0 ⇒ lim_{ x → 0^+ } (frac(sin(α * x), x)^{2}) = α^{2}

GOAL:
α ≥ 0 ⇒ (forall (x), x ∈ RealSet ∧ x > 0 ⇒ frac(sin(α * x), x)^{2} ≤ frac(1, x^{2}))
