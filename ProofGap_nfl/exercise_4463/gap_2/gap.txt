PROOF GAP @2
ASSUM:
1. y : RealSet → RealSet
2. forall (x), x ∈ RealSet ⇒ x^{2} + 2 * x * y(x) - y(x)^{2} = 2 * x
3. forall (x), x ∈ RealSet ⇒ 2 * x + 2 * x * FunDeri(y, 1, 1)(x) + 2 * y(x) - 2 * y(x) * FunDeri(y, 1, 1)(x) = 2

GOAL:
forall (x), x ∈ RealSet ∧ x ≠ y(x) ⇒ FunDeri(y, 1, 1)(x) = frac(1 - x - y(x), x - y(x))
